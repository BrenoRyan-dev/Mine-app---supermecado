# 🛒 Lista de Supermercado

Mini app que soma o valor dos itens do carrinho de compras e mostra o total na tela, ajudando a controlar quanto você vai gastar no supermercado.

🔗 **Online:** [brenoryan-dev.github.io/Mine-app---supermecado](https://brenoryan-dev.github.io/Mine-app---supermecado/)

## Sobre o projeto

Projeto de estudo para praticar lógica de programação e manipulação da página com JavaScript. O usuário informa os valores dos produtos e o app atualiza o total automaticamente.

## Funcionalidades

- Soma dos valores dos itens adicionados ao carrinho
- Exibição do total em reais (R$)
- Botão "Limpar" para zerar a lista e recomeçar

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages (hospedagem)

## Como rodar localmente

1. Clone o repositório:

```bash
git clone https://github.com/brenoryan-dev/Mine-app---supermecado.git
```

2. Entre na pasta:

```bash
cd Mine-app---supermecado
```

3. Abra o `index.html` no navegador, ou use a extensão **Live Server** do VS Code.

## Como usar

1. Informe o valor do produto.
2. Adicione ao carrinho.
3. Acompanhe o total atualizado na tela.
4. Clique em **Limpar** para começar uma nova compra.
